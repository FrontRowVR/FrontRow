4 · Prueba WebXR — aquí está el problema

Tres pruebas que aíslan la causa. Cada una entra al visor 20 s y mide el tiempo de cada frame. Ponte el visor antes de pulsar. Para salir antes, usa el botón del sistema.

Cómo leer el resultado:
A falla → el problema es la sesión WebXR, no el video.
A bien, C bien, B falla → el problema es subir el frame de 8K a la GPU en cada cuadro.
A bien, C falla → el problema es el tamaño de la textura de 8K en sí.
